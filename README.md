# Personal Finance Manager
A comprehensive command-line application for tracking personal finances, including income, expenses, and savings goals

# Features
Core functionality:
- Add, edit, and delete income/expense transactions
- Automatic saving to JSON with CSV export capability
- Pre-defined categories for better expense tracking
- Full date support with validation

Analytics & Reporting:
- View income, expenses, and net savings by month
- See where your money goes with category analysis
- Charts showing financial patterns over time
- Track progress towards financial targets

Data Visualization:
- Line graphs for income/expense trends
- Pie charts for category distribution
- Bar charts for monthly comparisons
- Progres bars for savings goals

# Quick Start
Prerequisites
- Python 3.7 or higher
- pip (Python package manager)

Installation:
1. Clone repository
   git clone https://github.com/A-n-sh/Personal-Finance-Manager
   cd personal-finance-tracker
2. Create a virtual environment (recommended)
   python -m venv venv
   venv\Scripts\activate
   source venv/bin/activate
3. Install dependencies
   pip install -r requirements.txt
4. Run the application
   python PFM.py
